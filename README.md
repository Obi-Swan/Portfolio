# Swan Deman - Premium multi-page portfolio

## Visualiser le site
1. Décompressez le ZIP.
2. Ouvrez `index.html`.

Pour une navigation locale plus fiable :
1. Ouvrez le dossier dans Visual Studio Code.
2. Installez l'extension **Live Server**.
3. Clic droit sur `index.html`.
4. Choisissez **Open with Live Server**.

## Publication GitHub Pages
1. Créez un dépôt GitHub.
2. Ajoutez tout le contenu du dossier à la racine.
3. `Settings` → `Pages`.
4. Source : `Deploy from a branch`.
5. Branche : `main`, dossier `/ (root)`.
