Great Place to Work Platform

An anonymous employee-feedback application connected to a Power BI platform for recurring global and team-level satisfaction analysis.

Power AppsSharePointPower BIDAXPower Query
Project origin

Requested employee-feedback solution.

The project was requested by Andrew Mortimer, Operations Manager - Port Operations, Calais & Dunkerque to collect feedback more frequently than the annual company survey and provide clearer team-level visibility.

My responsibility

Application and analytical architecture.

I designed the anonymous feedback journey, SharePoint data structure, Power Apps interface, Power BI model, DAX measures and analytical pages.

Application

Fast, intuitive and anonymous participation.

  • Anonymous feedback collection
  • Team selection
  • Recurring questionnaire
  • Smile-based satisfaction scale
  • Optional comments
  • Multiple workplace themes
  • Short completion time
  • User-friendly visual navigation
Power BI

From answers to actionable analysis.

The KPI needs were provided by Andrew Mortimer. I translated them into the data model, Power Query transformations, DAX measures and report pages while following DFDS visual templates.
